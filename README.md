## 📖 About This Repository

This repository contains **Python implementations** of the numerical algorithms presented in two classic textbooks:

- **Chapra, S. C. (2020).** *Numerical Methods for Engineers* (8th ed.). McGraw-Hill Education.  
- **Mathews, J. H. & Fink, K. D. (2004).** *Numerical Methods Using MATLAB* (4th ed.). Prentice-Hall.

While the original code in both books is written in MATLAB, this project ports the core algorithms to **Python** with a focus on:

- **Readability** – clear, well‑commented code.
- **Reproducibility** – exact outputs matching the textbook examples.
- **Extensibility** – modular functions that can be reused in larger projects.
- **Visualisation** – plotting convergence and function behaviour using `matplotlib`.
